## What a user must supply themselves

- **ImageNet-1k** (val split, 50,000 images; B2/B4 also need a train-split
  calibration subset). Every baseline and P2.1 script materializes this
  itself from the Hugging Face Hub given an `HF_TOKEN` (Colab) or a local
  ImageFolder-layout copy (`--imagenet-dir`, university/local GPU) — no
  raw image is committed to this repo.
- **Model checkpoints** — resolved automatically via `timm` from pinned
  tags (`deit_{tiny,small,base}_patch16_224.fb_in1k`,
  `vit_base_patch16_224.augreg2_in21k_ft_in1k`); no weights are committed.
- **The frozen 50k evaluation manifest**
  (`experiments/phase2_2_baselines/val_manifest_canonical.json`, hash
  `41ddeb0ebb2fea82`) guarantees every baseline evaluates the identical
  50,000-image set, in the identical order, regardless of which host
  materializes it — a fresh materialization is checked against this hash
  before any number from it is trusted (`common/notebook_self_test.py`'s
  data-determinism check).
